## Sobre o Projeto
InovDrop é uma plataforma que busca concentrar as contas e boletos, seja de uma pessoa ou de uma empresa, em um único local.

Na plataforma é possível:
- Anexar os arquivos PDF da conta
- Salvar informações importantes (valor, data de vencimento,...)
- Separar as contas dependendo da categoria a qual elas pertencem (Fixa, Fornecedores, Variadas)
- Manter o registro de contas já pagas e de suas informações.

## Melhorias futuras
- Automatizar o processo de aquisição dos dados da conta com ferramentas de AI.
- Criar uma área com gráficos para a análise dos dados (valor gasto no período, tipo de gasto,...).
- Separar o acesso das contas entre diferentes usuários.
